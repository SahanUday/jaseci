- **byLLM: a compaction no longer stores the system prompt in `conversation=`**: the system prompt was kept out of the caller's list by object identity, which a compaction defeats because it hands back copies. The stored copy was then sent next to the real prompt on every later call, and each further compaction stored another. `conversation=` now never holds a `system` message: it is skipped when the turn is written back and when the list is read, so lists that already hold one are healed on their next call.
